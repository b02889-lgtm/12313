# 代码审查工作流

## 步骤
1. 审查前准备 - 确认变更范围、阅读文档
2. 代码结构审查 - 检查文件组织、命名规范
3. 代码质量审查 - 检查可读性、注释、错误处理
4. 功能正确性审查 - 验证业务逻辑、边界条件
5. 性能审查 - 检查性能瓶颈、查询效率
6. 安全性审查 - 输入验证、敏感数据处理
7. 测试覆盖审查 - 单元测试、测试用例
8. 文档审查 - 文档字符串、README 更新
9. 审查反馈 - 提供建设性意见、改进建议
10. 审查后跟进 - 确认修改、验证结果
