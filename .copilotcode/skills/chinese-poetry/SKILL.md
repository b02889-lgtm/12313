# Chinese Poetry

中国古典诗词创作和鉴赏技能，提供专业的诗词创作指导。

## 核心功能

### 1. 创作古诗词

#### 绝句创作
- **五言绝句**：每句5字，共4句，20字
- **七言绝句**：每句7字，共4句，28字

#### 律诗创作
- **五言律诗**：每句5字，共8句，40字
- **七言律诗**：每句7字，共8句，56字

#### 词创作
- 支持常见词牌：水调歌头、念奴娇、沁园春、蝶恋花、浣溪沙等
- 严格遵循词牌格律要求

### 2. 创作对联

- **短联**：5-7字
- **中联**：8-11字
- **长联**：12字以上
- 要求对仗工整、平仄协调

### 3. 诗词格律检查

检查诗词是否符合以下规范：
- 平仄格律
- 押韵规则
- 对仗要求（律诗、词）
- 句式结构

### 4. 诗词鉴赏分析

提供以下分析：
- 格律分析
- 意象解读
- 典故说明
- 艺术特色
- 情感表达

## 创作流程

### 步骤1：确定主题和体裁
- 明确诗词主题（如：春天、思乡、送别等）
- 选择合适的体裁（绝句、律诗、词等）

### 步骤2：选择韵部
- 使用平水韵韵部（见 [references/yun-bu.md](references/yun-bu.md)）
- 确定韵脚位置

### 步骤3：构思意象
- 从意象库中选择合适的意象（见 [references/imagery.md](references/imagery.md)）
- 考虑意象的情感色彩和象征意义

### 步骤4：遵循格律
- 按照平仄规则创作（见 [references/ping-ze.md](references/ping-ze.md)）
- 词创作需遵循词牌格律（见 [references/ci-pai-list.md](references/ci-pai-list.md)）

### 步骤5：检查和润色
- 检查平仄是否正确
- 检查押韵是否和谐
- 检查对仗是否工整
- 润色语言，提升意境

## 使用示例

**创作七言绝句**：
```
用户：帮我写一首关于春天的七言绝句
系统：创作符合格律的七言绝句，押平水韵
```

**创作词**：
```
用户：创作一首词，词牌《水调歌头》，主题是中秋
系统：按照水调歌头格律创作中秋主题的词
```

**格律检查**：
```
用户：检查这首诗的格律是否正确
系统：分析平仄、押韵、对仗等格律要求
```

## 注意事项

1. 严格遵循传统格律规范
2. 使用平水韵作为押韵标准
3. 注意平仄交替和对仗工整
4. 意象选择要与主题相符
5. 语言要典雅，避免白话
