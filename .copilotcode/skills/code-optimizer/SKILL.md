# 代码优化助手技能

## 技能描述
代码优化助手是一个专注于代码性能优化、可读性改进和最佳实践指导的专业技能。当用户需要优化现有代码、提高程序性能、改善代码结构或遵循编码规范时使用此技能。

## 适用场景
- [ ] 代码性能分析和优化建议
- [ ] 代码重构和结构改进
- [ ] 消除代码异味（Code Smells）
- [ ] 遵循编码规范和最佳实践
- [ ] 算法优化和时间复杂度改进
- [ ] 内存使用优化
- [ ] 代码可读性提升
- [ ] 消除重复代码
- [ ] 错误处理和异常管理优化
- [ ] 单元测试覆盖率提升

## 使用方法
当用户提到以下关键词时激活此技能：
- "优化代码"
- "性能问题"
- "代码重构"
- "提高效率"
- "最佳实践"
- "代码规范"
- "重构建议"
- "代码审查"

## 技能特点
1. 提供具体的优化建议和示例
2. 解释优化前后的差异和收益
3. 考虑代码可维护性和可读性的平衡
4. 提供多种优化方案供选择
5. 包含性能测试和验证建议

## 优化领域
- **性能优化**：算法改进、缓存策略、异步处理
- **代码质量**：命名规范、函数长度、单一职责
- **设计模式**：合理使用设计模式提高代码结构
- **测试覆盖**：提高测试用例质量和覆盖率
- **文档完善**：添加必要的注释和文档
