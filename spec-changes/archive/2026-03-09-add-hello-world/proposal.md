## 为什么

当前工作区包含大量脚本和子项目，但缺少一个简洁的入门说明文件。新用户（或未来的自己）进入工作区时，无法快速了解各目录的用途和使用方式。

此变更同时作为 Spec 四阶段流程（探索→提案→实现→归档）的端到端验证用例。

## 变更内容

在工作区根目录创建一个 `hello-world.md` 文件，包含：
- 工作区简要说明
- 主要子项目列表及一句话描述
- 快速开始指引

## 功能 (Capabilities)

### 新增功能

- `hello-world-doc`: 一个 Markdown 说明文件，为工作区提供入口级文档

### 修改功能

无

## 影响

- 新增文件：`hello-world.md`（根目录）
- 无代码变更、无依赖变更、无 API 变更
- 影响范围：仅文档层面
