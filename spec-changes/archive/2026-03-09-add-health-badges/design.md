## 上下文

`hello-world.md` 是工作区的入口级导航文件，当前包含一个 3 列表格（项目 | 描述 | 技术栈）。在探索阶段，我们发现 6 个子项目的健康状况差异较大（有的缺 README，有的缺测试），但从表格上无法直接看出。

## 目标 / 非目标

**目标：**

- 在项目表格中增加"状态"列，用 emoji 徽章直观展示每个项目的健康维度
- 在表格下方添加图例说明
- 保持表格简洁，不增加过多视觉噪音

**非目标：**

- 不自动检测项目状态（手动维护，保持简单）
- 不修改任何子项目的代码或文件
- 不添加 CI 自动徽章生成脚本

## 决策

1. **状态维度**：选择 3 个最直观的维度
   - 📖 README（有无文档）
   - 🧪 测试（有无测试文件/目录）
   - 📦 依赖（有无 requirements.txt / package.json / pyproject.toml）

2. **展示方式**：在表格新增第 4 列"状态"，每个项目用空格分隔的 emoji 表示已具备的维度。缺少的维度不显示 emoji（而非显示 ❌），这样视觉更清爽。

3. **图例位置**：紧接表格下方，用一行小字说明各 emoji 含义。

4. **维护方式**：手动更新。当项目新增 README 或测试时，开发者需自行更新表格。

## 风险 / 权衡

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 状态信息过时 | 低 | 手动维护足够（项目数量少） |
| emoji 在某些终端渲染异常 | 低 | 选用广泛支持的 emoji |
| 增加表格宽度 | 低 | 状态列内容简短，影响可控 |
