## 为什么

当前 `hello-world.md` 的子项目一览表只展示了项目名称、描述和技术栈，但无法一眼看出各项目的**健康状况**——例如是否有文档、是否有测试、是否有依赖管理文件。

开发者在浏览工作区时，往往需要快速判断哪些项目是"可直接使用"的（文档齐全），哪些需要额外投入（缺少文档或测试）。添加健康状态徽章可以显著提升导航效率。

## 变更内容

在 `hello-world.md` 的子项目表格中增加一列"状态"，使用 emoji 徽章标注每个项目的文档、测试、依赖完备度：

- 📖 有 README
- 🧪 有测试
- 📦 有依赖文件（requirements.txt / package.json / pyproject.toml）

同时在表格下方添加徽章图例说明。

## 功能 (Capabilities)

### 新增功能

- `health-badges`: 在项目导航表格中以 emoji 徽章形式展示每个子项目的文档/测试/依赖状态

### 修改功能

无

## 影响

- 修改文件：`hello-world.md`（仅文档变更）
- 无代码变更、无依赖变更、无 API 变更
- 影响范围：仅文档层面
